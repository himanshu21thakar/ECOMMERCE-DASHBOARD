# 📊 Madhav E-Commerce Sales Dashboard

A Power BI interactive dashboard built to analyze sales, profit, and customer behavior using e-commerce order data.  
This project provides a complete end-to-end data visualization of business performance across states, categories, payment modes, and monthly trends.

---

## 📝 **Project Description & Purpose**

This project aims to help businesses understand their sales patterns and customer insights by using Power BI.  
The dashboard provides a clear view of:

- Total sales amount  
- Profit and quantity distribution  
- Best-selling states, categories & sub-categories  
- Monthly profit trends  
- Customer-wise sales contribution  
- Payment mode behavior  

The purpose is to support **data-driven decision-making** for marketing, inventory planning, and revenue growth.

---

## 🛠 **Tech Stack**

| Tool / Technology | Purpose |
|------------------|---------|
| **Power BI Desktop** | Data modeling, visualization, dashboard creation |
| **Power Query** | Data cleaning & transformation |
| **DAX (Data Analysis Expressions)** | Measures & calculated fields |
| **CSV Files** | Raw dataset |

---

## 📂 **Data Source**

The dashboard is built using the following uploaded datasets:

- **Orders.csv** — Contains order details (date, amount, quantity, profit, state etc.)  
- **Details.csv** — Contains product category, sub-category, and customer-level details  

Both files are included in the project repository:
- `/mnt/data/Orders.csv`
- `/mnt/data/Details.csv`

## ⭐ **Features / Highlights**

### ✔ KPI Cards  
- Total Amount (438K)  
- Total Profit (37K)  
- Total Quantity (5615)  
- Average Order Value (121K)

### ✔ Visualizations Included  
- **Profit by Month** (Bar Chart)
- **Amount by State** (Horizontal Bar Chart)
- **Quantity by Category** (Donut Chart)
- **Profit by Sub-Category** (Bar Chart)
- **Amount by Customer Name** (Bar Chart)
- **Quantity by Payment Mode** (Donut Chart)

### ✔ Filters  
- **Quarter Filter (Q1–Q4)**  
- **State Filter (All / Individual)**  

### ✔ Business Insights  
- Clothing contributes the largest share (63%)  
- Maharashtra leads in total sales  
- COD is the most used payment method  
- Profit dips during April & September  
- Printers and bookcases are top profit-making sub-categories
